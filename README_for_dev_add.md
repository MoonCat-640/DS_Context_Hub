# 补充工作

## 1、打包

将其最终打包成一个可以直接运行的软件，包括其需要的各种支持，最终客户双击运行ds_context_hub.exe即可直接运行

## 2、制作安装包

为该软件制作一个离线安装包Setup.exe，用户双击运行该软件离线安装包的Setup.exe程序，Setup.exe通过UAC询问用户并获取管理员权限，启动安装引导，选择安装过程中的语言后，选择软件本体的安装位置，并敲定安装的细节（例如为当前用户安装还是为全体用户安装，是否添加到PATH等），进行安装，安装完成后，生成指向该软件实际运行程序（WX_msg_grb.exe）的快捷方式，双击快捷方式后即可打开软件。

## 3、Github Release发布

将离线安装包发布到Release
